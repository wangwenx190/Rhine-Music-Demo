# 验证输出与Git边界

本文只维护产物保留规则；来源身份归source-provenance.md，采样含义归performance.md，欠验归迁移计划R36。

- Git保留源码、产品资产、真正测试输入、必要参数/来源契约和简明结论。截图/差分/逐帧JSON/场景导出/原始性能序列/日志/机器矩阵/hash清单为本地输出，不提交。
- `verification/`、`docs/media/`均忽略。需要原始证据时本地或仓库外归档，失败不能覆盖或改写为通过。
- 忽略规则不构成保留理由。仅保留剩余任务的输入、仍有效且用于复用的结果、未决失败的原始证据；确认被完整后续结果覆盖的中间批次、临时浏览器profile、重复构建及无消费者的数据应删除。验证工具仅保留现行门槛及其依赖；测试与审计目录、构建及入口边界见[test-gates.md](test-gates.md)。产品构建与资产生成独立保留。
- 确需入库证据仅保留不可缺少的最小核心，优先既有契约的简短结论/未决项/最小复现/来源标识；图片或大文件须用户明确指定个别文件，不因保留历史全量入库，不改名fixture/contract绕过。
- 按明确路径暂存，提交前检查清单/数量/体积，排除生成目录、重复副本和私人路径/配置/曲库。
- 普通构建/CTest使用提交资源和tests/fixtures。已提交的独立数学/结构JSON直接消费；缺输入显式失败，不用被测实现、空目录或默认值伪造期望，不重建旧Web工程补输入。
