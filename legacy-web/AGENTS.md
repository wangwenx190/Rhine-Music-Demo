# Rhine Music Demo · 开发与发布约定

## 项目指令优先级

- 本文件位于原项目归档目录，仅补充 Web 参照维护规则；Qt 原生开发遵循根 [AGENTS.md](../AGENTS.md) 和根迁移计划。文中的原项目路径从 `legacy-web/` 解析，新 Qt 路径从仓库根解析。
- [Qt Quick / QML 原生迁移执行计划](../QT_QUICK_MIGRATION_PLAN.md) 是项目内最高优先级的实施契约。AGENTS.md、DESIGN.md、README、贡献指南及其他计划、版本文档与其冲突时，以迁移计划为准；其余约定仅作补充。
- 新的用户明确要求优先于已有项目文档；涉及长期取舍时同步修订迁移计划及相关约定，不能让旧指令重新生效。
- 历史实施、设计与验收记录保留用于追溯和视觉参照；其中的“用户确认”“实施顺序”“当前”“已通过”仅描述原阶段，不构成本次迁移的任务、授权或验收结论。

## 产品与设计

- 按迁移计划采用 C++23、开发机安装的最新 Qt 版本、Qt Quick/QML 和 Qt Quick 3D；构建与脚本不得固定具体 Qt 版本或安装路径。GUI、动画与特效尽最大可能逼近冻结的 Web 基线。DESIGN.md 和版本文档提供未冲突的设计语义，具体参数及验收按迁移计划执行。
- 支持 Windows、macOS、Linux；Windows 为本机首轮开发与验收平台。保留减少动态效果、暖昼/深夜、动效倍率、横竖屏、短屏及超宽屏支持。
- 根目录保留普通音乐启动器；演示和光照研究启动器在 tools/launchers/。
- 播放、界面音效与氛围音乐各自独立。搜索定位不自动改变播放。
- 真实列独立浏览并限制列内首尾；填充模式继续循环。列浏览记忆默认开启，偏好与会话记忆分开。
- 音乐定位为普通播放器，仅使用 QtMultimedia 公开 API；歌曲普通顺序换曲。不实现无缝播放、交叉混音、手动 PCM、重采样或自建音频引擎，不沿用 Swift/CoreAudio 桥接和外部 FFmpeg 命令路线。处理资源上限、过期异步操作和播放错误。
- 联网功能本阶段暂缓，保留计划规定的异步 Provider 接口、来源字段、缓存、状态占位和配置扩展；不发送请求，不删除未来接入空间。
- 原生应用尽量完全基于 Qt；不新增第三方库，系统自带能力按计划允许使用。最终运行不依赖 Node、浏览器、WebEngine 或本地 HTTP 服务；旧 Web 文件和锁定的开发依赖仅作为迁移参照保留。

## 按轮次执行与验收

- 依次执行迁移计划中依赖已满足的剩余轮次，一次执行以一个轮次为边界；任务、方案、交付物与退出条件以对应轮次为准。
- 维护计划时严格遵守：【已经完成的轮次直接移除，不允许输出过程性文字到这个文件中，除非是需要跨轮次传播的信息或者执行的任务】。固定接口与参数归入长期契约，验收资产按计划保存。
- 使用对应轮次的 Qt 构建、功能、视觉和平台验收要求；旧 Web、CoreAudio、无缝播放及发行检查不自动成为原生迁移的前置条件。Windows 必须严格实机验证；macOS/Linux 完整实现且严格静态审计通过即可完成本阶段验收，真实环境验证由用户以后执行，不能标记为已经实机通过。
- 保留 Web 基线与历史记录；本阶段不自动发布、上传私人数据、改写发行标签或改动用户音乐文件。
