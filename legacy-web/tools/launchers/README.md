# 开发与演示启动器

> **迁移约定：** 入口位置与后续改造以 [Qt 迁移计划](../../../QT_QUICK_MIGRATION_PLAN.md) 为最高优先级：普通音乐启动器在根目录，演示和光照研究启动器在本目录。原生启动最终不依赖 Node、浏览器或 HTTP 服务。

## 现有 Web 启动器（迁移基线）

普通使用请双击工程根目录的 `启动音乐播放器.command`。

- `启动演示.command`：构建并预览内置三张演示封面，没有可播放歌曲。
- `启动光照实验.command`：光照调试开发服务。

这两个入口使用独立端口，关闭终端窗口停止服务；首次运行会安装锁定依赖。脚本会自动进入所属版本的根目录，不依赖终端当前目录。
