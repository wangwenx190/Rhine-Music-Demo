# Observatory / 观测室 · 音频来源

`atmosphere.ogg`、`motif.ogg`、`pulse.ogg`为LBEILC在上游RhineLabUI中原创程序编配的同步循环声部；`observatory-preview.mp3`为带首尾淡变的独立试听版，`score.json`为谱面。没有原片采样、外部录音或人声。源谱保存在同目录`score.json`；合成源码为上游V0.4.1历史路径`scripts/render-audio.mjs`，可在Git历史追溯。原生项目直接使用这些已提交音频，不运行合成脚本。

这些配乐沿用项目MIT许可；代码作者及第三方资产权利边界以随包`project/NOTICE.md`及`project/project-LICENSE`为准（源码仓库位于`resources/licenses/`）。本说明唯一维护这些音频的作者与来源，当前播放路由和界面音效可用性见源码仓库`docs/contracts/playback.md`。
